Koinon is pre-alpha, so expect things to move. Open an issue before a large change, and read the
relevant decision records first.

The developer documentation lives in the Koinon repository, next to the code, and is not part of
this site.

- [CONTRIBUTING.md](https://github.com/stateracloud/koinon/blob/main/CONTRIBUTING.md). How to start:
  the sign-off rule for commits (the Developer Certificate of Origin), the rules for AI-assisted
  contributions and the tools you need.
- [Architecture decision records](https://github.com/stateracloud/koinon/tree/main/docs/adr). Why
  Koinon is built the way it is. Read the ones that touch your change before you start.
- [Developer guides](https://github.com/stateracloud/koinon/tree/main/docs/dev). The local
  development loop, how CI runs, how to test and how releases are cut.
- [Glossary](https://github.com/stateracloud/koinon/blob/main/GLOSSARY.md). The words Koinon uses
  and what they mean.

## Issues

Issues for the code and for these pages are in one place, the
[Koinon repository](https://github.com/stateracloud/koinon/issues). Documentation issues carry the
`docs` label.

## Changing these pages

The pages are in [koinon-docs](https://github.com/stateracloud/koinon-docs). Every page has an
"Edit this page" link. A pull request there needs a site build, working links, commands that equal
the ones the Koinon repository tests, and signed-off commits.
